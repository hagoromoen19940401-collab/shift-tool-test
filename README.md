# シフト管理ツール（操作テスト版）

介護シフトの自動生成・編集・Excel出力ができる、HTML 1枚のツールです。
**操作感を確かめていただくためのテスト配布版**です。

## 使い方

下のURLを開くだけです。インストールは不要です。

**▶ (公開後にURLをここに記載します)**

iPhone・iPad の場合は、開いたあと画面下の共有ボタンから「ホーム画面に追加」すると、
アプリのように起動できます。

## ⚠ テストのお願い

- **実際の職員名・勤務データは入力しないでください。**
  「テスト太郎」「職員A」など、**架空の名前**でお試しください。
- 入力した内容は**お使いの端末のブラウザの中だけ**に保存されます。
  サーバーには送信されず、他の人からは見えません。
- 他の端末・他のブラウザには引き継がれません。

## 試していただきたいこと

1. **職員マスター** … 架空の職員を数名登録する（ユニット・勤務形態・基本休日数を設定）
   - 氏名の左の「≡」や「▲▼」で並び替えができます
2. **希望休入力** … 希望休・有休・希望勤務を入れてみる
3. **シフト自動生成** … 月を選んで「シフトを自動生成」を押す
   - セルをクリックして手動修正できます
   - 「生成結果・修正案内」で不足や注意点を確認できます
4. **Excel出力** … その月の勤務表を .xlsx で保存する
5. **勤務コード設定** … 勤務コードの追加・時刻・色を変更する

使いにくかった点、分かりにくかった表示、欲しい機能などをお聞かせください。

## データの受け渡し（JSONファイル）

職員マスター画面の下部にボタンがあります。

- **全データをJSON保存** … 今のデータを1つのファイルに書き出します
- **全データをJSON読込** … 書き出したファイルを選ぶと、その場で反映されます

読込は「ボタンを押す → ファイルを選ぶ」だけです。
すでにデータがある端末では、置き換えの確認が1回だけ出ます。

> ファイルの中身は**お使いの端末の中だけ**で処理されます。どこにも送信されません。

## データの保存について

- データはブラウザ内にのみ保存されます。
- **ブラウザの履歴やサイトデータを消すと、入力内容も消えます。**
- iPhone・iPad では、**7日間開かないと自動的に消える**ことがあります。
- 大事なデータは「全データをJSON保存」で手元に控えてください。
